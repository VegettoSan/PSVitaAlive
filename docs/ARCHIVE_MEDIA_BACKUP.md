# Existing-item artwork preservation

The existing VPK batch and VitaForge initial creation are unchanged. A separate module runs after them under the existing catalog-publisher lock. It scans icons/screenshots independently of VPK version, processes up to three external images per execution, and uses the historical owned-item CSV (or corroborated current canonical links) to locate an existing item. An inferred mapping is recorded in the CSV only after successful verified preservation. Missing or ambiguous destinations are reported, never guessed. Item ownership is rechecked before any upload.

Initial sources: explicit GitHub artwork hosts over HTTPS only, with each redirect validated. Other hosts are reported as SOURCE_REVIEW until an adapter is approved. PNG/JPEG/static WebP only, real decoding with Pillow, 8 MiB per image, dimensions at most 4096x4096. No Game/Data Files, no VPK changes, no deletion or replacement of historical files. Archive.org URLs are skipped; a conflicting external Archive item is not migrated automatically. Existing generic fallback icons are skipped where recognized.

A content-addressed filename (media_<SHA256>.<ext>) prevents collision; existing same-size/MD5 images can be reused only after public SHA-256 verification. Durable per-source checkpoint precedes PUT. Never retry a potentially accepted PUT automatically; reconcile via item manifest and complete public verification. Only then rewrite exact matching icon/screenshots URLs in the original canonical JSON, keeping screenshot order and all other fields. Source URL changes during pending operations require review. The registry/checkpoint is internal (data/archive_media_backup_jobs.json), never consumed by Vita/web. Generated catalogs remain owned by validate.yml.

Report: archive-backup-batch-report/media.json. Initial rollout is bounded (3 images, 5-minute processing budget, 8-minute job-step timeout). Offline tests run before any transfer. CI and a real verified media upload must be checked before widening provider coverage or batch size.
