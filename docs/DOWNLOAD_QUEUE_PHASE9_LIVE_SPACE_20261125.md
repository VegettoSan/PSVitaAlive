# Live staging reservations

The queue now credits only successfully written serial/parallel contiguous staging prefixes, rounded down to MiB. The HTTP worker publishes a lower bound; destructive retry, range fallback, joining and cleanup invalidate the epoch before any shrink. The main thread captures this prefix before the mount free-space probe and discards credit if its epoch changed. A growing writer is conservatively overcharged between samples; no UI progress is trusted. Paused jobs retain the existing stopped-worker disk check. Extraction, promotion, uncertain size and system handoff continue to use conservative estimates and authoritative native checks; exact output size is not guaranteed before archive inspection. Tests cover epoch invalidation and monotonic growth. Native/hardware testing pending.
