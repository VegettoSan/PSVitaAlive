# Contextual storage and catalog memory — main integration

Restores the original contextual storage implementation from PR #119 / commit 96e564e, tested as Build #899. The main-side controller edge tracker is preserved. The interim replacement from bda6c0e is superseded; its catalog-specific labels and saved ZIP cleanup guards remain. No generated catalog or release version is changed.

- Homebrew keeps the existing package and declared Game/Data Files inspector. Vita, PSP and PS1 use the original scanGames implementation, bounded SFO/PBP/ISO/CISO metadata parsing, physical-path identity, size sorting, separate persistent caches and checked deletion. See CONTEXTUAL_STORAGE_MANAGER_PLAN_20261126.md for the original design and limitations.
- ZIP recovery appears only in Homebrew. Other tabs do not scan, count, display or authorize saved ZIP cleanup. Clean all maps to temporary files only, including direct action guards. Catalog and image caches remain protected.
- Before the catalog worker parses a cache miss or transfers a new payload, evict all decoded inactive catalog vectors under the existing mutex. Free vector capacity, not only elements. The requested catalog is retained; before applying an actual soft update, release its redundant manager copy only after the UI has consumed the cached publication. The visible UI payload and on-disk validated cache are not evicted.
- Publish ready vectors by move, not a second worker copy. Network updates do not create an additional full RAM copy during hot-swap. Returning to a freed tab may require reading its disk cache again. Normal memory-cache hits remain available until eviction. No network transfer or persisted catalog is deleted by this policy.
- Tab switches release old filtered vector capacity and inactive Homebrew storage candidates; workers and install-session locks are preserved. Saved ZIP display metadata may fall back to its saved name/icon placeholder if the corresponding decoded catalog is no longer retained.
- Hardware regression: switch Homebrew -> Vita Games during cache-first update, refresh unchanged/changed/offline, rapid tab switch during soft refresh, verify memory logs, selection preservation, saved ZIP cleanup only in Homebrew, all four installed-content modes, duplicate physical paths, deletion with backups and controller edge behavior.

Build #899 validated the original branch, not this merged revision. CI and physical-console tests are required for the combined revision. No stable release is authorized by this integration.
