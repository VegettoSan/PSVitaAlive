# PSVitaAlive 02.20 — Download Manager & Multitasking Update

A major update for the native PS Vita / PSTV client focused on managing multiple downloads, browsing while installations run, and reducing interruptions in the interface.

## Download manager
- Add multiple applications or Install All groups to a single queue without leaving the catalog.
- A dedicated footer button opens the manager, with application icons, current task, pending tasks, progress and component details.
- Internal installation steps execute one at a time in FIFO order. The active group appears first, waiting groups follow, and finished groups move to the end with an animated transition.
- Pause, resume and cancel when supported by the current operation. Confirmations and installer ownership checks remain in place.
- Transfer size, speed, ETA and extraction progress are shown when available. Unknown totals are not fabricated.
- Persistent download history with icons, result details and explicit recovery of eligible pending jobs after restarting the client.
- Interrupted or ambiguous jobs require review; this is not automatic byte-level resume across app restarts. A BGDL handoff is not treated as a completed system installation.

## Safer installation and storage
- Combined capacity checks across selected components and destination mounts, with conservative handling of unknown sizes.
- Recalculate active size estimates when the actual HTTP payload exceeds catalog metadata.
- Credit only stable staged bytes; preserve existing ZIP/path validation, native installer routes and shell/power protection.
- If space is insufficient, open restricted storage maintenance and explicitly retry the queue.

## Interface and controls
- Animated icon feedback when adding a job; animated reordering in the manager.
- Navigate queue, history, recovery and step details with the left analog stick or D-pad, including held-direction scrolling.
- START follows the current focus: catalog cards → footer → header → catalog cards. Tabs count as the header section.
- OLED protection activates after one minute of inactivity during a protected session and shows current operation, component, progress, pending count and battery.
- Localized download manager in all eight existing client languages.

## Performance
- Icon file reads and PNG decoding move to the existing image worker during queue sessions; the UI uploads bounded pixel buffers to GPU textures.
- Reduce passive installed-state and saved-ZIP storage probes during protected sessions.
- Cooperative ZIP extraction scheduling also covers preflight and small files.
- Bounded performance diagnostics help identify remaining slow frames without per-frame log spam.

Physical Vita tests of the queue baseline completed multiple large ZIP installations and showed a substantial reduction in observed slow frames. Results vary with storage, package contents and user interaction; no fixed FPS or speed improvement is guaranteed. Mascot startup, some explicit storage checks and job transitions remain areas for further optimization.

## Install or update

Open PSVitaAlive with automatic updates enabled, or download the official **PSVitaAlive.vpk** and install it over your existing app using VitaShell.
