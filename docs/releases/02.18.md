# PSVitaAlive 02.18

**02.18** updates the native PS Vita / PSTV client with a V1/V2 catalog reader and usability and memory-management improvements. This client is released **before** the public JSON catalog format switches to V2.

## Highlights

- **Catalog compatibility:** reads V1 and compact V2 Homebrew, author, category, PS Vita, PSP and PS1 metadata, and preserves support for previously cached V1 catalogs.
- **Game Files status:** shows a localized alert if a port is installed but all known required Game Files folders are missing.
- **Screenshot memory:** retains screenshots as long as their actual rendered rectangles intersect the viewport; continues freeing off-screen GPU textures through the safe deferred-release mechanism.
- **Readable details:** wraps long requirements, descriptions and metadata to the actual text width.
- **Installed-data management:** clearer APP-only, Game Files-only and combined removal options, appropriate warning text, and consistent confirmation dialogs.
- **Visual fixes:** improvements to marquee clipping, modal overlap and eight-language interface labels.
- **Web and tools:** supports both schema formats without changing published catalog content ahead of the client.

## Safe catalog rollout

This is the **compatibility update**. Public catalogs remain V1 at the time 02.18 is published. Only after this release and its VPK are confirmed available will a separate change introduce compact V2 JSON. Updating to 02.18 first is important: old clients with disabled, failed or cancelled updates may not be able to read V2.

## Install or update

1. Download **PSVitaAlive.vpk** from the release assets below.
2. Install over the existing PSVitaAlive using VitaShell, or use its built-in release updater.
3. Reopen PSVitaAlive after installing the update.

**Title ID:** `PSVAS1178`  
**Version:** `02.18`

The official VitaSDK release workflow checks the VPK's internal `APP_VER`, Title ID, ZIP integrity, and attached SHA-256 checksum.
