# PSVitaAlive 02.19 — UI Redesign & Stability Update

A major update for the native PS Vita / PSTV client, with a refreshed interface, better controller navigation, improved download recovery, safer installation and storage management, and catalog reliability improvements.

## New interface and navigation
- Sprite-based visual skin with consistent rounded panels, dialogs, buttons, focus indicators, progress bars and physical controller hints.
- Refreshed catalog, app details, keyboard, settings, theme picker, installation, storage, reports and QR dialogs.
- Navigate header, catalog and footer with physical controls; improved touch-aware focus, incomplete grid rows and loading-screen input protection.
- Theme selection now distinguishes browsing from applying a color. The last explicitly applied theme is saved on confirmation or exit.
- Fixed clipping, scrolling and unexpected position changes in feedback panels.

## Performance and stability
- Batched nine-slice rendering and safe GPU vertex reuse.
- Bounded text layout cache, off-screen draw culling, asynchronous image filesystem checks and budgeted texture decoding.
- Reduced redundant storage lookups and hidden modal rendering. No specific FPS or memory improvement is claimed.

## Downloads and installation
- Automatic recovery from transient network interruptions with bounded retries and backoff.
- Retains validated partial progress, respects manual pauses, protects HTTP ranges and prefers alternate Archive.org nodes when appropriate.
- Improved handling of transient MediaFire resolution failures and unsafe resume responses.
- Stronger pre-download free-space checks, combined Install All budgeting, ZIP extraction progress and safe existing-file extraction optimization.
- Partial downloads are preserved during the current client session only; recovery across app restarts is not supported.

## Storage and catalog
- More readable storage manager with catalog icons for retained ZIPs, scan progress, synchronized touch targets and clearer deletion confirmations.
- Informed warnings for shared Game Files, with affected app names, Title IDs and installed status; preserves unrelated ur0 dependencies.
- Automatic recovery from unexpectedly empty catalogs, safe cache replacement and fallback to validated in-memory catalogs.
- Optimized JSON parsing without changing the catalog schema; fewer redundant HTTP requests.
- Corrected Homebrew version comparison for alpha, beta, preview, release candidate and stable releases.
- Updated all eight existing UI languages: English, Spanish, French, German, Italian, Brazilian Portuguese, European Portuguese and Russian.

## Install or update
Existing users can open PSVitaAlive with its built-in automatic update enabled. It checks GitHub Releases and downloads the official update when available. Alternatively, download **PSVitaAlive.vpk** below and install it over the existing app with VitaShell.

**Version:** `02.19`  
**Title ID:** `PSVAS1178`

The official release workflow validates the VPK ZIP integrity, internal APP_VER, Title ID and SHA-256. The UI redesign was approved on physical PS Vita hardware; the final release binary is rebuilt from main.
