# PSVitaAlive 02.17

**02.17** is a usability and reliability update for the native PS Vita / PSTV client. It builds on 02.16 and incorporates fixes tested on real PS Vita hardware.

## What's new

### Cleaner catalog interface
- Application/game cards no longer display the release date. Their version, file size, status, installed badge, and Game Files / Data Files indicators remain visible.
- The release date remains available in app details; date-based sorting is unchanged.
- The filter button shows the selected filter's localized name, with marquee scrolling for long text.
- With no active content filter, the button says **Filters**, not **Show All**.

### PSP and PS1 installation
- Shows the selected `pspemu` destination during PSP/PS1 PBP and ISO/CSO installations, or the destination folder while unpacking supported PKGs.
- Shows the actual installation path in the completion dialog.
- Installed-game badges show the storage mount (such as **Installed ux0** or **Installed uma0**); long labels marquee without changing card dimensions.
- Detects PSP/PS1 files on `ux0`, `uma0`, `imc0`, and `xmc0` using the cached installation index.
- Refreshes the index after successful PSP/PS1 installation, including cases without a returned Title ID.
- Corrects status text that could mislabel PSP/PS1 installations as generic ZIP extraction.

### Stability and performance
- Fixes flickering when completing a VPK installation launched with the **Update** button.
- Defers installation-badge refresh until after the result dialog closes.
- Removes an accidental duplicate UI update/render call in the main loop.
- Avoids per-chunk destination-path allocations while copying large PSP/PS1 files.
- Preserves existing Downloads and Install All behavior.

### Discord and community
- Updates the in-client Discord QR and public links to the current official invitation: https://discord.gg/byn8FDuDrw
- Adds Discord forum thread routing for user-written problem reports and suggestions, while retaining separate automated diagnostic reporting.
- Adds GitHub Actions catalog notifications for Discord.

## Install or update

1. Download **PSVitaAlive.vpk** from the assets attached below.
2. Install with VitaShell over your existing PSVitaAlive installation.
3. Alternatively, existing users can use the client's built-in release updater.

**Title ID:** `PSVAS1178`  
**Version:** `02.17`

The VPK is compiled by GitHub Actions with the official VitaSDK image. Release automation checks that its internal APP_VER is `02.17`, its Title ID is `PSVAS1178`, and the archive passes CRC verification. A SHA-256 file accompanies the VPK.
