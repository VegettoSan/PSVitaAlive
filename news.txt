# Thanks for using PS Vita Alive Store.

Not all Homebrew / Ports have Game Files yet, please be patient as I will gradually upload them so they can be downloaded.

We use Archive.org as our Homebrew database, which may cause downloads to take a little while to start, please be patient.

# What's New

## Improvements

- Interface notifications were added to prevent **confusion** during **downloads and installations**.
- The way the system handles downloads and retries for slow networks or connection failures during downloads has been improved.
- A patch has been implemented to fix the issue where the app would get stuck loading the PS1 catalog when launching.
