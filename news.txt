# What's New in 02.13

## New Built-in Keyboard

- Completely replaced the native PS Vita keyboard with a custom QWERTY keyboard.
- Improved stability by removing the native IME from text input.
- Supports touchscreen, D-pad, and left analog stick navigation.
- Added numbers, special characters, persistent SHIFT, and hold-to-delete.
- Smooth animations and full compatibility with the selected color theme.
- Keyboard interface translated into all eight supported languages.

## New Catalog Filters

- Added a new filtering panel for all four catalogs.
- Filter Homebrew by category, installed status, and available updates.
- Filter PS Vita, PSP, and PS1 games by genre and installation status.
- Added Game Files, Data Files, and DLC filtering.
- Filters can be combined with text searches.

## Installed Games Detection

- Improved detection of installed Homebrew and games.
- Added support for detecting PS Vita, PSP, and PS1 installations.
- Improved compatibility with Adrenaline, ISO, CSO, and EBOOT.PBP.
- Added detection across supported storage devices.

## Installation and Stability

- Fixed incorrect ZIP/VPK detection for Game Files and Data Files.
- Improved ZIP extraction safety and file protection.
- Improved cancellation and retry handling.
- Optimized storage space checks for different installation types.
- Improved overall installation reliability.

## Interface Improvements

- Added a battery percentage indicator to the catalog header.
- Battery information is also available in OLED protection mode.
- Improved interface navigation and touchscreen alignment.
- Updated translations across all eight supported languages.
- Additional bug fixes, performance improvements, and catalog updates.
