# What's New in 02.15

## Improved Plugin Management

- Added confirmation before installing individual plugins.
- Plugins are now classified as Required, Optional, or Not Specified.
- Added the option to reinstall already detected plugins when their version cannot be verified.
- Improved plugin detection using active taiHEN configuration.
- Safer plugin replacement with backup and recovery protection.

## Better Install All Experience

- Improved installation of VPK, Game Files, Data Files, and plugins.
- Install All now continues processing remaining steps when an individual installation fails.
- Added a detailed installation summary showing successful, failed, and skipped operations.
- Improved plugin installation confirmations and restart handling.
- Fixed issues affecting installation queues when catalog filters change.

## Automatic ZIP Recovery

- Added automatic ZIP preservation after supported extraction failures.
- Recoverable ZIP files are automatically saved after a 10-second countdown.
- Install All can continue processing remaining downloads after successful recovery.
- Added options to keep or safely delete recovered ZIP files.
- Improved recovery protection to prevent accidental file deletion.

## Optimized ZIP/VPK Extraction

- Improved extraction performance when replacing existing files.
- Reduced unnecessary temporary copies and storage usage.
- Improved free-space calculations for file replacements.
- Added protection against filename collisions and source archive overwrites.
- Improved handling of extraction failures and incomplete files.

## Startup Cleanup & Catalog Updates

- Added automatic cleanup of abandoned downloads during startup.
- Improved protection for previously saved ZIP archives.
- Added visible progress during storage maintenance.
- Added catalog synchronization progress indicators.
- Improved notifications when catalog updates are downloaded and applied.

## Additional Improvements

- Improved overall installation reliability.
- Updated messages across all eight supported languages.
- Improved plugin installation safety and user control.
- Better error handling and filesystem protection.
- Additional performance improvements and bug fixes.

### Tips:
- iTLS-ENSO (full) recommended for HTTPS.
- DNS: 8 8 8 8 / 8 8 4 4.
- Keep NoNpDrm (and NoPspEmuDrm if you use LiveArea PSP/PS1).
- Restart your PS Vita after installing system plugins.
- If Archive.org is unavailable, try another download source or retry later.
- Report installation issues with session.log when possible.
