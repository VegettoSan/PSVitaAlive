# What's New in 02.14

## Faster Downloads

- Improved parallel downloading for VPK, ZIP, Game Files, and Data Files.
- Added direct extraction of compatible segmented ZIP/VPK downloads.
- Reduced unnecessary file assembly and processing.
- Improved Archive.org server selection and download stability.
- Optimized large downloads and automatic fallback handling.

## Faster ZIP/VPK Extraction

- Improved extraction performance for archives containing many small files.
- Added optimized directory caching to reduce filesystem operations.
- Improved file creation and extraction efficiency.
- Maintained safe file replacement, CRC checks, and ZIP64 compatibility.
- Tested extraction improvements on real PS Vita hardware.

## Archive.org Connection Warnings

- Added automatic Archive.org connectivity checks.
- Added warnings when external download services cannot be reached.
- Improved detection of unavailable files and download sources.
- Reduced unnecessary retries for unreachable servers.
- Added recommendations to try alternative download links.

## Better Error Messages

- Added clearer explanations for download and installation failures.
- Improved messages for network, HTTP, TLS, and MediaFire errors.
- Added specific warnings for corrupted archives and storage problems.
- Improved troubleshooting instructions.
- Updated error messages across all eight supported languages.

## Website Improvements

- Refreshed application cards and catalog layouts.
- Improved Homebrew, PS Vita, PSP, and PS1 browsing.
- Redesigned application details and developer profiles.
- Improved download links and recommended download indicators.
- Enhanced mobile responsiveness and navigation.

## Additional Improvements

- Improved download and installation stability.
- Reduced unnecessary filesystem operations.
- Expanded automated regression tests.
- Added new Homebrew and developer profiles.
- Updated catalog information and download links.
- Additional performance improvements and bug fixes.

- Report installation issues with session.log when possible.
