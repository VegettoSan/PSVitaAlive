# What's New

## Improvements

- Fixed ZIP extraction issues with deeply nested folders.
- Improved compatibility with large Homebrew and Game Files archives.
- Added a new **Recovered ZIPs** section to retry saved archives without downloading them again.
- Added individual recovery buttons for multiple saved ZIPs.
- ZIP archives are now automatically cleaned up after successful extraction.
- Failed extractions preserve ZIP files for later recovery.
- Improved download assembly speed and SHA-1 verification.
- Improved installation safety, recovery handling, and interface navigation.
- Updated translations across all eight supported languages.
- Additional stability improvements, bug fixes, and catalog updates.
