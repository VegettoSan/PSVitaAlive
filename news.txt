# PSVitaAlive 02.17 is now available!

A focused update bringing a cleaner interface, better PSP/PS1 installation information, and several reliability fixes. Thanks for testing these changes on real PS Vita hardware!

---

## A Cleaner Catalog

- Release dates have been removed from app and game cards to reduce clutter.
- The version, download size, status and installed indicators remain visible.
- Release dates are still available inside each application's details.
- The filter button shows the active filter name, with scrolling text for longer labels.
- With no active filter, the button now simply says **Filters**.

## PSP and PS1 Storage Improvements

- Installation progress shows where PSP/PS1 games are being saved.
- The completed installation screen shows the resulting destination.
- Installed badges can identify the storage device, such as **Installed ux0** or **Installed uma0**.
- Detection covers supported PSP/PS1 paths on ux0, uma0, imc0 and xmc0.
- Better install status refresh and clearer completion messages.

## Stability Fixes

- Fixed flickering when an app finishes installing from the **Update** button.
- Removed an unnecessary duplicate UI render.
- Reduced work during large PSP/PS1 file copies.
- Downloads and Install All keep their existing behavior.

## Discord Community

- The Discord button and QR now use the updated invitation.
- The manual feedback system can send problem reports and suggestions to their dedicated forums.

Join our community: https://discord.gg/byn8FDuDrw
