# Thanks for using PS Vita Alive Store.


## Not all Homebrew / Ports have Game Files yet, please be patient as I will gradually upload them so they can be downloaded.


## We use Archive.org as our Homebrew database, which may cause downloads to take a little while to start, please be patient.


## It is recommended that when downloading very heavy Homebrews/Ports, do not go out to the LiveArea, do not suspend the PS Vita with the power button, as this prevents downloads or installations from being damaged.


# What's New

## Improvements

### The problem of extracting Game Files larger than 2GB has been fixed.
## App startup times have been improved.

- Catalogs are now loaded only on demand, optimizing RAM usage and improving app startup speed.
- A button has been added to request Data/Game Files from homebrews that don't yet have them.
- Log collection in reports has been improved.
- Downloads are not paused or canceled if the console automatically turns off the screen.
